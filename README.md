# ALIEN OUTVASION

A ~30-minute, fully procedural, real-time 3D animated short film. Everything you see and hear (models, textures, animation, music, sound, voices) is generated by code in the browser with [three.js](https://threejs.org) and WebAudio — no image, model or audio files.

**Play it:** open `alien-outvasion.html` (self-contained, ~1 file) in a modern browser (Chrome, Edge, Firefox, Safari; desktop or phone). Click **Begin**.
Best experienced with headphones, in landscape, full-screen. Quality is auto-selected (phones start at Low); you can override it on the start screen.

Controls — `Space` play/pause · `←/→` ±10 s · `F` full-screen · `C` subtitles · `M` mute · `D` debug overlay · seek bar & buttons (touch friendly).
URL options — `?t=SECONDS` start time · `?q=0|1|2` hint · `?autostart` skip the start screen.

## Build

```
npm install
npm run build          # -> alien-outvasion.html (+ index.html), minified, three.js inlined
node tools/build.mjs --dev   # unminified
```

## Repository layout

| path | what |
|---|---|
| `src/engine/` | shared engine: `common` (math/RNG/quality), `proc` (noise + canvas texture toolkit), `geo` (geometry helpers), `infect` (green infection shader), `lipsync` (text → visemes → mouth params), `stage`, **`director`** (timeline/scenes/post/HUD/audio), `scene` (SceneContext authoring API), `actor` (time-keyed actors & entities), `camera` (shot rigs + auto dialogue coverage), `hud` |
| `src/models/` | human rig/faces/clothes/animation, crowds, alien beings, alien machines, vehicles |
| `src/world/` | sky/space/ocean/terrain/vegetation, cities & landmarks, interior sets |
| `src/fx/` | particles/explosions/weather, post-processing, adaptive performance |
| `src/audio/` | procedural music, SFX, ambience, voices |
| `src/film/` | the film itself: scene definitions in runtime order |
| `src/demos/` | stand-alone demos used with the still-frame harness |
| `tools/` | `build.mjs`, `render.mjs` (demo stills), `shotfilm.mjs` (player screenshots), `smoke.mjs` (every-scene smoke test) |
| `docs/CONTRACT.md`, `docs/api/*` | engineering contract and per-module API notes |

## Authoring model (short)

A scene is `{ id, dur, build(S) }`. `S` (a `SceneContext`) registers **time-keyed** content — actors with movement/animation tracks, entities with paths, camera shots (with automatic dialogue coverage), dialogue lines (lip-synced + subtitled + voiced), HUD overlays (date stamps, name cards, titles), audio cues, post-processing keys. Everything is a pure function of scene time, so the player can seek anywhere (`director.seek(t)` rebuilds the scene and fast-forwards silently).

See `docs/PASS2_NOTES.md` for known issues and the cheapest iteration loop.

## Testing

```
node tools/render.mjs --demo human_cast --out out/human      # still frames of a demo (headless Chromium, software GL)
node tools/shotfilm.mjs --times 10,95,400                    # screenshots of the real player (DOM HUD + canvas) at film times
node tools/build.mjs --dev && node tools/smoke.mjs           # every scene at several times: errors, draw calls, triangles, timings
```
